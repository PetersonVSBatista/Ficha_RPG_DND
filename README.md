# 🐉 Fichas de RPG - D&D 5e

Um projeto web interativo para criação e gerenciamento de fichas de personagens para Dungeons & Dragons 5ª Edição. O objetivo é automatizar cálculos e facilitar a organização das informações do jogador durante as mesas de RPG.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação das páginas.
* **CSS3:** Estilização e layout temático (`rpg-style.css`).
* **JavaScript:** Lógica de cálculos e interatividade (`Atributos.js`).

## 🚀 Funcionalidades Atuais
* Estrutura visual base da ficha de personagem.
* Layout responsivo com tema de fantasia.

1. Faça o clone deste repositório no seu terminal:
   `git clone https://github.com/PetersonVSBatista/Fichas-RPG-mesa-DND.git`
2. Navegue até a pasta do projeto.
3. Abra o arquivo `index.html` diretamente no seu navegador de preferência.
